# 听见 Plus

听见 Plus 是一个面向普通用户的交流与思考插件。它会先理解用户的感受和现实处境，再根据当前需要陪用户表达、整理问题、理解关系或探索下一步。

当前版本：`1.0.1`

## 安装方法

### 第一步：添加插件市场

在 `PowerShell（Windows 命令窗口）`或其他终端中运行：

```powershell
codex plugin marketplace add lin528908-boop/tingjian-plus-marketplace
```

### 第二步：重启应用

完全退出并重新打开 `ChatGPT Desktop（ChatGPT 桌面端）`。

### 第三步：安装插件

打开 `Plugins（插件）`，找到 `听见插件`来源，然后安装 `听见 Plus`。

## 开始使用

新建聊天后，可以这样开始：

> 我有一件事情想说。请先认真听我说，再陪我慢慢理清楚。

## 更新方法

在终端中运行：

```powershell
codex plugin marketplace upgrade tingjian-marketplace
```

然后完全退出并重新打开 `ChatGPT Desktop（ChatGPT 桌面端）`。

## 能力边界

- 帮助表达感受、整理思路、理解关系互动和探索个人成长。
- 不替用户作重大决定。
- 不诊断精神障碍、心理疾病或人格障碍。
- 不替代医疗、心理治疗、法律或财务专业服务。

## 隐私说明

本插件是技能说明型插件，不需要 OpenAI API Key（接口密钥），也不会要求用户提供与当前交流无关的身份信息。
